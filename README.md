# nrf52832_ble

nRF52832 BLE peripheral project based on nRF5 SDK v17.0.2 and S132 SoftDevice 7.2.0.

Open the Keil project at:

`examples/ble_peripheral/ble_app_template/pca10040/s132/led_ble/ble_app_template_pca10040_s132.uvprojx`

The repository includes the SDK source tree because the project references files through relative paths. Keil build output and per-user settings are excluded. SDK and third-party license notices are in `documentation/licenses.txt` and the respective source directories.
